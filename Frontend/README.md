# LearnAI - Frontend
Plain HTML/CSS/JS (no build step). Pages: index.html (login/register), dashboard.html (dashboard, profile, skill form, learning path, courses, video lectures, quiz, performance, progress, AI tutor). The Video Lectures page links each course to matching YouTube lecture search results.
Run: double-click start.bat (serves on http://127.0.0.1:5500). Backend URL is set in js/api.js.
