# Python Learning Roadmap
Weeks 1-2: syntax, variables, data types, conditionals, loops. Practice with small programs such as a calculator and number guessing game.
Weeks 3-4: functions, lists, dictionaries, tuples, sets, file handling and error handling. Build a to-do list app in the terminal.
Weeks 5-6: object oriented programming, modules, virtual environments, pip. Build a small project that uses an API.
Next steps: pandas for data, FastAPI for backend, scikit-learn for machine learning.
Tip: solve one small coding problem every day to build logic.
