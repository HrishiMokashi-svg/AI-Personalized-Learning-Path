# Career and Soft Skills
Communication: practice explaining technical ideas in simple words. Record yourself presenting and review it.
Portfolio: keep three strong projects on GitHub with clear README files.
Interview preparation: practice data structures, SQL queries and project explanations. Do mock interviews with friends.
Teamwork: learn Git collaboration, code reviews and clear written updates.
Design interest: learn UI/UX basics, color, typography and prototyping to make projects look professional.
