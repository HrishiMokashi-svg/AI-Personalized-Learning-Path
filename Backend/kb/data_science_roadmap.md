# Data Science Roadmap
Foundation: statistics (mean, median, variance, probability, hypothesis tests) and basic linear algebra.
Tools: Python, pandas, NumPy, matplotlib. Learn to clean data, handle missing values and visualize trends.
Machine learning: regression, classification, clustering, model evaluation, cross validation, overfitting and underfitting.
Projects: house price prediction, student performance analysis, customer segmentation.
Tip: weak in math? Study statistics with real datasets and visual explanations first.
