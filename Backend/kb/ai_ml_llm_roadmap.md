# AI, LLM and RAG Roadmap
Start with Python and machine learning basics. Then learn how large language models work: tokens, context windows, temperature and prompting.
Prompt engineering: give a role, context, examples and an output format. Ask for JSON when the app needs structured output.
Embeddings turn text into numeric vectors so similar meanings are close together.
RAG (Retrieval-Augmented Generation): split documents into chunks, embed them, store vectors, retrieve the most similar chunks for a question and add them to the prompt so the model answers using trusted information.
Projects: a document chatbot, a study assistant, a personalized recommendation system.
