# Web Development Roadmap
Frontend: learn HTML structure, CSS layout (flexbox and grid), then JavaScript (DOM, events, fetch API). Build a landing page, then a dashboard.
Backend: learn a framework such as FastAPI or Express, REST design, authentication with JWT, and validation.
Database: learn SQL and MySQL basics, tables, relations and joins, then connect the backend with an ORM like SQLAlchemy.
Deployment: learn Git, environment variables and basic hosting.
Tip: build projects instead of only watching tutorials.
